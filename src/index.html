Claude Code 연결

Claude Code 설정 파일의 env 에 아래를 넣으면 모든 트래픽이 이 앱을 거칩니다. 경로는 CLAUDE_CONFIG_DIR 설정에 따라 다릅니다 — 아래 진단에서 찾아 줍니다. 
"CLAUDE_CODE_ENABLE_TELEMETRY": "1",
"OTEL_METRICS_EXPORTER": "otlp",
"OTEL_EXPORTER_OTLP_PROTOCOL": "http/protobuf",
"OTEL_EXPORTER_OTLP_ENDPOINT": "http://localhost:4319"
원래 수집 서버로 계속 보내려면 그 주소를 위 전달할 서버 주소 에 넣으세요. 이 앱이 받은 내용을 그대로 넘깁니다.
이미 실행 중인 세션에는 반영되지 않습니다. 새 터미널에서 claude 를 실행하세요.
