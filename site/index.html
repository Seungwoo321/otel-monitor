텔레메트리는 조용히 나갑니다

Claude Code 의 OpenTelemetry 를 켜면 사용량 메트릭이 주기적으로 전송됩니다. 다만 전송 내역이 로컬에 남지 않아, 무엇이 얼마나 나가는지 확인할 방법이 마땅치 않습니다.

1

전송 성공·실패 기록이 로컬에 남지 않습니다.

2

실패는 claude --debug 로만 드러나 평소엔 알아채기 어렵습니다.

3

설정을 바꿨을 때 실제로 무엇이 달라지는지 눈으로 볼 수 없습니다.

중간에 세워두고 들여다봅니다

로컬에서 OTLP 를 받아 디코딩·기록한 뒤, 설정한 수집 서버로 바이트를 그대로 넘깁니다. 기존 수집을 끊지 않고 내용만 들여다볼 수 있습니다.

Claude Code │ OTLP/HTTP (protobuf) ▼ OTel Monitor :4319 ← 디코딩 · 기록 · 유출 감지 │ 원본 그대로 릴레이 ▼ 원래 수집 서버 (선택 — 비워두면 로컬 전용 뷰어)

기능

내용 유출 감지

프롬프트·응답 원문이나 도구 파라미터가 페이로드에 포함되면 알려줍니다. 로그 신호가 켜진 것도 함께 표시합니다.

실시간 수신 스트림

요청 하나하나를 시각·크기·메트릭명·응답과 함께 보여줍니다. 선택하면 전체 속성을 펼쳐 봅니다.

개인 식별 정보 표시

user.email·organization.id 같은 식별 속성을 따로 색으로 구분해 드러냅니다.

누적 통계와 차트

토큰·비용·커밋·코드 변경·활동 시간을 집계하고 시계열로 그립니다. cumulative 누계를 정확히 처리합니다.

설정 진단

settings.json 을 직접 읽어 내용 노출 키 6종이 켜져 있는지 확인해 줍니다.

내보내기

수집한 캡처를 JSON·CSV 로 저장합니다. 데이터는 메모리에만 있고 외부로 나가지 않습니다.

시작하기

  1. 앱 설치
    DMG 를 받아 Applications 로 옮깁니다. 공증돼 있어 경고 없이 열립니다.
  2. Claude Code 설정
    Claude Code 설정 파일의 env 에 아래를 넣습니다. 경로는 CLAUDE_CONFIG_DIR 에 따라 다르며, 기본은 ~/.claude/settings.json 입니다.
    "CLAUDE_CODE_ENABLE_TELEMETRY": "1",
"OTEL_METRICS_EXPORTER": "otlp",
"OTEL_EXPORTER_OTLP_PROTOCOL": "http/protobuf",
"OTEL_EXPORTER_OTLP_ENDPOINT": "http://localhost:4319"
  3. 새 세션 시작
    새 터미널에서 claude 를 실행합니다. 최대 1분 뒤 첫 전송이 도착합니다.
이미 수집 서버로 보내고 있다면 그 주소를 앱 설정의 전달할 서버 주소 에 넣으세요. 받은 내용을 그대로 넘깁니다. 앱을 꺼두면 그 구간은 전달되지 않습니다.

무엇이 잡히나

Claude Code 가 내보내는 메트릭은 8종이 전부입니다. 전부 숫자입니다.

메트릭의미
session.count세션 시작 횟수
token.usage토큰 (input / output / cacheRead / cacheCreation)
cost.usage비용 (USD)
lines_of_code.count수정한 줄 수 (added / removed)
commit.count커밋 개수
pull_request.countPR 개수
code_edit_tool.decision편집 권한 승인 · 거절
active_time.total실제 활동 시간 (초)
값은 숫자 집계이고 대화 내용은 포함되지 않습니다. 다만 로그인 상태에서는 user.email·organization.id 같은 식별 속성이 함께 붙습니다. 인스펙터가 이 속성들을 따로 표시해 줍니다.
